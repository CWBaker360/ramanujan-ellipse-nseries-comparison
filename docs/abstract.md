# Abstract

This note compares Ramanujan's second ellipse-perimeter approximation with
polygonal N-Series geometric acceleration. Ramanujan provides an exceptional
closed-form approximation, especially near the circular case. The N-Series
uses two-scale and three-scale cancellation to suppress leading even-power
polygonal errors. In the tested cases, the three-scale refinement overtakes
Ramanujan's formula at moderate and high eccentricity.
